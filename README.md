# Cult Trainer RU

Русскоязычный трейнер Cult of the Lamb для Windows x64. Версия **1.4.0**, подготовлена для Steam-сборки **25223484** на Unity Mono.

## Скачать и запустить

[Скачать готовый EXE](https://github.com/Whitee99/Trainer-Cult-of-The-lamb/raw/refs/heads/main/downloads/CultTrainerRU.exe). Python для запуска EXE не нужен. Контрольная сумма — в `downloads/SHA256SUMS.txt`.

1. Запусти `CultTrainerRU.exe` и нажми «Запустить игру». Библиотеки Steam находятся автоматически; другую папку можно выбрать на странице «О программе».
2. Дождись зелёного индикатора подключения и загрузи сохранение.
3. Включи нужные функции переключателями или горячими клавишами.

При первом запуске устанавливается игровой модуль. Если игра уже открыта без него или была обновлена версия модуля, перезапусти игру. Перед установкой копируются существующие сохранения.

## Вызов прямо из игры

Нажми **Insert** или кнопку **«Трейнер [Insert]»** в правом верхнем углу игры. Окно трейнера восстановится поверх игры; если приложение закрыто, модуль запустит зарегистрированный EXE. Первый раз EXE нужно запустить вручную для установки и регистрации пути.

Повторный запуск EXE открывает существующее окно без создания второго трейнера. Игра автоматически не ставится на паузу при открытии окна.

## Функции

| Клавиша | Функция |
| --- | --- |
| F1 | Бессмертие Агнца |
| F2 | Множитель подбираемых ресурсов ×2–×100 |
| F3 | Ускоренная молитва у святилища |
| F4 | Отсутствие голода у последователей |
| F5 | Бесконечная энергия последователей |
| F6 | Максимальная вера культа |
| F7 | Бесплатное строительство |
| F8 | Проклятия без расхода рвения |
| F9 | Предотвращение нового инакомыслия |
| F10 | Защита от болезней |
| Insert | Открыть окно трейнера из игры |
| Ctrl + F12 | Отключить все функции |

Во вкладке **«Квесты»** появляются незавершённые цели, отслеживаемые справа в игре. Кнопка **«Выполнить»** завершает выбранную цель через игровой менеджер заданий. Следующие этапы цепочки не выполняются автоматически; награды, требующие разговора, забираются у персонажа. Перед командой создаётся копия существующих файлов сохранения.

Во вкладке **«Дополнения»** переключатель **«Открыть все DLC»** обрабатывает восемь игровых проверок доступа для Cultist, Heretic, Sinful, Pilgrim, Woolhaven и бонусных наборов. Действует для контента в установленных файлах игры; сюжетные условия открытия локаций сохраняются. Покупки Steam не изменяются.

Потребности применяются при обновлении игровых показателей. Уже существующий бунт может требовать перевоспитания. Множитель действует на обычные подбираемые ресурсы; награды заданий и покупки не умножаются.

Трейнер нужно оставить открытым во время использования функций. При закрытии функции отключаются; при аварийном завершении связь истекает через 5 секунд. Полученные предметы и изменения показателей могут остаться в сохранении.

## Установка, резервные копии и удаление

Исходная `Assembly-CSharp.dll` не заменяется. Устанавливаются официальный BepInEx 5.4.23.6 и `BepInEx/plugins/CultTrainerRU/CultTrainer.dll`. Если обнаружен неизвестный `winhttp.dll`, автоматическая установка останавливается.

Резервные копии и служебные файлы находятся в `%LOCALAPPDATA%/CultTrainerRU`. Удаление модуля доступно на странице «О программе» после закрытия игры. Удаляются только установленные трейнером файлы с совпадающими контрольными суммами; копии сохранений остаются.

## Сборка из исходников

Требуются Windows x64 и Python 3.13.

```powershell
python -m pip install -r requirements.txt
.\setup-dependencies.ps1
python -m PyInstaller --noconfirm CultTrainerRU.spec
```

Результат — `dist/CultTrainerRU.exe`. В репозитории есть скомпилированный авторский модуль `plugin/CultTrainer.dll`. Для его пересборки требуется установленная игра:

```powershell
.\build.ps1
```

Скрипт зависимостей скачивает закреплённую версию BepInEx из официального релиза и проверяет SHA-256. Исходные игровые DLL и ресурсы не загружаются в репозиторий.

## Проверки

```powershell
python test_show.py
python test_dlc.py
python test_quests.py
```

Эти тесты проверяют восстановление окна, маршрутизацию выбранного квеста, защиту от повторных запросов, команды DLC и сохранение включённых функций при обновлении приложения. Они не меняют действующее игровое сохранение.

В установленной игре дополнительно проверялись загрузка модуля, игровые проверки показателей, все десять команд, отключение по потере связи и переключение DLC. Полное прохождение всех игровых сценариев и сравнительный замер FPS не выполнялись. Совместимость после обновлений игры может измениться.

Файловый обмен выполняется в фоновом потоке. Квесты опрашиваются раз в секунду только при открытой вкладке или ожидающей команде; переводы кэшируются, неизменившиеся снимки не перезаписываются.
